## 1 引言

### 1.1 编写目的

本计划开发的目的是：

a. 把 TreasureShare 玩具租赁共享平台开发过程中各项工作人员、分工、系统资源等问题的安排用文档形式记录，以便根据本计划开展和检查本项目工作，保证项目开发成功。

b. 制定项目组开发过程中的计划，明确相关工作的负责人员，并规定软件配置的内容及要求。

### 1.2 背景

- **软件名称**：TreasureShare（玩具租赁共享平台）
- **提出者**：Ciami
- **开发者**：Ciami（组长）、王博康、钱嘉铭、童子鸣、任俊丞
- **用户**：有闲置玩具租赁需求的个人用户
- **适用平台**：Web 端（跨平台），支持移动端浏览器访问

## 2 项目概述

### 2.1 工作内容

本项目开发过程中需要进行的各项主要工作为：

1. **需求分析**：调研闲置玩具租赁共享场景，编写需求分析报告
2. **系统设计**：概要设计、详细设计、数据库设计
3. **编码实现**：
   - 后端：基于 Spring Boot + MyBatis + RuoYi 框架开发 RESTful API
   - 前端（用户端）：React 19 + TypeScript + Vite 6 + Tailwind CSS 4
   - 前端（管理端）：Vue 2 + Element UI
4. **测试**：单元测试、集成测试、端到端测试（Playwright）
5. **部署上线**：Linux 服务器部署
6. **文档编写**：项目计划书、需求分析报告、概要设计说明书、详细设计报告、数据库设计报告、测试报告

- 测试报告
- 用户手册
- 项目总结报告

### 3.5 关键问题

3. **文件上传大小限制**：玩具图片上传需限制文件大小和格式
4. **订单状态机正确性**：订单生命周期状态流转需严格按设计执行

## 4 支持条件

### 4.1 计算机系统支持

**硬件**：
- 开发环境：PC 机（16GB RAM，4 核 CPU 及以上）
- 推荐配置：DDR4 16GB 内存，1TB SSD 硬盘

**软件**：
- 操作系统：Linux (推荐 Arch Linux / Ubuntu)
- JDK 17+
- Node.js 18+
- Maven 3.6+
- MySQL 8.0+
- Redis 7.4+
- Nginx 1.x

### 4.2 需由用户承担的工作

无需用户承担额外工作（本项目为课程作业性质）。

### 4.3 由外单位提供的条件

- 无外单位依赖，所有组件自建。

## 5 专题计划要点

- **版本控制**：使用 Git 进行代码和文档版本管理
- **编码规范**：遵循 Java 阿里巴巴编码规范，前端使用 ESLint + Prettier
- **测试策略**：后端 JUnit 单元测试 + 前端 Playwright 端到端测试
- **部署方案**：使用 `start.sh` 脚本一键启动所有服务
