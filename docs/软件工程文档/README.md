## 编译图片

在有 LaTeX 环境的机器上执行：

```bash
cd images
bash build.sh
```

所需依赖：`texlive-latexextra`、`poppler-utils`（或 `imagemagick`）

## 填写说明

1. 每份填写指南按模板 docx 的章节顺序组织
2. `[插入 images/XX.png]` 标记表示该处需要插入对应图片
3. 方括号 `[]` 中的内容是需要你根据实际情况微调的部分
4. 正文内容可直接复制到 docx 中，适当调整格式
5. 各表格需要在 Word 中重新创建（指南中给出表头和示例数据）
