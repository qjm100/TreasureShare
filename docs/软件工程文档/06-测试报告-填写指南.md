## 1 引言

### 1.1 编写目的

对 TreasureShare 平台各功能模块进行系统性测试，记录测试用例、测试结果及发现的缺陷，评估软件质量，为项目验收提供依据。适合开发人员和项目管理人员阅读。

### 1.2 背景

- **名称**：TreasureShare（玩具租赁共享平台）
- **提出者**：Ciami
- **开发者**：Ciami（组长）、王博康、钱嘉铭、童子鸣、任俊丞
- **测试环境**：
  - 浏览器：Chrome 120+, Firefox 120+, Safari 17+（桌面端）
  - 移动端：iPhone 14 Pro (Safari) 视口测试
  - 测试框架：Playwright (E2E)
  - 测试报告：`TEST_REPORT.md` (12 pass / 0 fail / 1 skip)

### 1.3 定义

| 术语 | 定义 |
|------|------|
| E2E | 端到端测试 (End-to-End)，模拟真实用户操作 |
| Playwright | 微软开源的浏览器自动化测试框架 |
| 功能测试 | 验证系统功能是否符合需求规格 |
| 非功能测试 | 验证系统性能、安全性、可用性等非功能需求 |
| 测试用例 | 一组测试输入、执行条件和预期结果的集合 |
| 缺陷严重程度 | 缺陷对系统影响的等级划分 |

### 1.4 参考资料

- 《软件工程导论》 作者：张海藩
- Playwright 官方文档
- `front/tests/` 目录下的测试脚本

## 5 对软件功能的结论

### 5.1 商品模块

#### 5.1.1 能力

商品浏览、搜索、分类筛选、详情查看、发布商品、图片上传等功能均正常运行，满足需求规格说明。

#### 5.1.2 限制

- 图片上传大小限制为 5MB
- 搜索仅支持名称匹配，不支持全文搜索

### 5.2 订单模块

#### 5.2.1 能力

订单全生命周期状态流转（创建→支付→发货→收货→归还→消毒→完成）逻辑正确，续租和取消功能正常。

#### 5.2.2 限制

- 支付为模拟支付，无真实支付网关集成
- 物流单号为手动输入，未对接物流 API

### 5.3 消息模块

#### 5.3.1 能力

消息发送、接收、会话列表、未读提醒等功能正常。

#### 5.3.2 限制

- 消息通过页面刷新/轮询获取，非 WebSocket 实时推送
- 不支持多媒体消息（图片/文件）

### 5.4 社区模块

#### 5.4.1 能力

帖子发布、评论、点赞功能正常，支持富文本内容。

#### 5.4.2 限制

- 社区帖子不支持编辑和删除（前端限制）
- 未实现帖子分类/标签

### 5.5 评价模块

#### 5.5.1 能力

星级评分、评价内容提交、商品评价展示正常。

#### 5.5.2 限制

- 评价不支持修改或删除
- 不支持追加评价/追评

### 5.6 管理后台

#### 5.6.1 能力

数据看板、订单管理、商品管理、用户管理等管理功能正常。

#### 5.6.2 限制

- 数据看板统计为实时查询，数据量大时可能较慢

## 6 分析摘要

### 6.1 能力

TreasureShare 平台核心功能均已实现并通过测试，包括：用户注册登录（JWT 认证）、商品浏览搜索发布、购物车、订单全生命周期管理、即时消息、社区互动、商品评价、管理后台等。系统运行稳定，可满足玩具租赁共享的业务需求。

### 6.2 缺陷和限制

| 缺陷编号 | 缺陷描述 | 缺陷严重程度 |
|----------|---------|-------------|
| [如有] | [描述] | [致命/严重/一般/轻微] |

已知限制：
1. 支付为模拟支付
2. 消息为非实时推送
3. AI 推荐功能依赖外部 Gemini API

### 6.3 建议

1. 集成真实支付网关（如支付宝/微信支付）
2. 消息模块升级为 WebSocket 实时通信
3. 增加商品全文搜索引擎（如 Elasticsearch）
4. 增加移动端原生 App
5. 增加数据导出和报表功能

### 6.4 评价

TreasureShare 玩具租赁共享平台已达到项目预期目标，核心业务流程完整，功能测试通过率达标，可以交付使用。
