## 填写指南结构

每份指南按模板章节顺序组织，包含：
- 章节编号和标题
- 该节应填写内容说明（基于 TreasureShare 实际代码和架构）
- 可直接使用的文字段落（关键部分）
- 图表插入位置标注（`[插入 images/XX.png]`）

## 技术实现

- LaTeX 编译：使用 `pdflatex` + `convert` 或 `pdftoppm` 将 TikZ 源码编译为 PNG
- 图片尺寸：统一适配 A4 页面宽度（约 15cm 宽）
- Markdown 格式：标准 GFN，中文 UTF-8
